# Deciding evidence and useful partial answers (#172)

This follows the [explicit correction boundary](../current-corrections/README.md). It addresses an
earlier correlated copy remaining current when the original booking was never admitted, and a whole
compound answer being withheld despite independently supported details.

Automatic retention now compares admitted deciding records with earlier retained assertions in their
precise source group. Correlation and revision numbers only bound that comparison. An exact source
quotation, matching attribution and a separately prompted semantic verification must establish the
same assertion, explicit withdrawal and faithful readable representation. Confirmed older copies stay
inspectable as historical support. Unresolved comparisons persist a current hold for the affected
pair; a held source can establish only withdrawal uncertainty, never accepted replacement facts.

Answers exclude restricted records from both generation and verification. Independent evidence can
produce a verified partial answer carrying `current_correction_pending` and
`pending_memory_correction`. A definite, self-attested user schedule can be expressed as a booked
departure whether extraction classifies it as an event or a claim. Source reports, tentative plans and
other qualifications retain their attribution requirements; semantic verification still checks actor,
status and occurrence. The caller authority of provided candidates is unchanged.

Deterministic regressions cover the untargeted copy, unresolved relationship, all-held source intent,
preview byte preservation, unchanged replay, restart/rebuild, later resolution, independent payment,
retraction and undo. Answer tests distinguish direct schedules from source reports in English and
Russian. The migration test and a separate check using the actual released schema-47 migration source
preserve receipts and correction state at schema 48. The complete local gate passes 4,666 tests,
build, lint, unused-code checks and built CLI/socket/client smoke tests.

## Separate socket/client control

An invented fixture deliberately refuses the original booking, admits an earlier correlated copy and
an independent single payment, then extracts a later correction without an addressed retained target.
On the final built core/socket/client path, the `gpt-5.6-luna` derive attempt makes the older copy
historical and answers the April 22 departure, unchanged payment and occurrence uncertainty with a
verified citation. The `gpt-6-luna` attempt holds the unresolved schedule pair and answers only the
independently admitted unchanged payment. Both preserve restriction state and Markdown bytes across
restart/rebuild and unchanged replay. These focused controls are reported separately from the frozen
combined-question comparison.

## Limits and evidence binding

This closes a bounded current-meaning safety boundary, not the broader semantic quality evaluation.
Typed holds can still be conservative and useful coverage still depends on extraction, admission,
retrieval and answer verification. A broad source group or unavailable bounded comparison can hold
independent assertions too; callers should declare precise correlation groups. An unresolved plan remains held after an unrelated journey is
retracted; that is not counted as recovery. No extra booking, payment or occurrence may be inferred
from a copy or correction.

One earlier held-out `gpt-6-luna` maintained answer attaches the journey date to payment completion,
although the source establishes only that the payment was made. That separate temporal-scope failure
is recorded in [#187](https://github.com/tenphi/akno/issues/187); the successful later correction does
not erase it. This comparison is not a passing broader quality estimate.

The frozen input review and source corpus hashes bind unchanged invented source text. The discourse
runner's `sourceBytesUnchanged` control does not inspect its skeletal destination pages; it is not
evidence that every authored Markdown page stayed byte-identical. The deterministic held-write tests
and focused restart snapshots establish byte preservation at those boundaries.
