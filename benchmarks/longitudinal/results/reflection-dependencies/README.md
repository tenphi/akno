# Exact reflection dependency boundary

This is the bounded repair for [#173](https://github.com/tenphi/akno/issues/173), following the
[frozen lifecycle baseline](../lifecycle-baseline/README.md). It does not revise that baseline or
claim improved natural observation/reflection admission.

A new L3 conclusion seals its exact selected L2 identities, canonical marker hashes, payload
hashes, scope-assessment fingerprint, and visible sentence hash. Qualification follows current
native L2 eligibility and exact leaf bytes, even before a watcher indexes a leaf edit. Missing
support makes only that conclusion inspectable history. Current factual recall, automatic
context, and answers cannot use it as supported evidence; requesting `all` does not restore
support. Explicit reads, pins, and historical recall preserve accurate qualification.

No L3 fact rows are necessary for this boundary. Owned reflection payloads cannot be mined into
L1 facts, and older such rows are removed before graph construction. Legacy generated principles
without exact lineage are historical until a freshly assessed replacement is appended. Indexing
changes only the disposable projection, never the Markdown.

The preliminary ordinary-generation replay used one repetition of each development/held-out

This diagnostic cohort preceded the final all-view exclusion and curator-invariant clarification;
its recorded artifact inventory must not be represented as the final production contract.
A correctly bounded candidate reached the scope gate, but the curator requested a more useful
higher-order conclusion; revising its wording could not inherit the old scope receipt. Curator
instructions now explicitly require a new candidate and fresh assessment for changed meaning.

Separate positive controls use the same two frozen source sets and exact previously reviewed
finite-session aggregations. Candidate generation is scripted, scope assessment and non-leaf
indexing are live, and the authoring agent explicitly approves the exact assessed plan through the
ordinary socket review/apply interface. This is operator-reviewed dependency calibration, not
natural generation or autonomous curator usefulness coverage. Live read, graph-enabled recall,
automatic context, answer generation/verification, unchanged cycles, and restart/rebuild then
exercise the bound conclusion across the declared leaf correction and complete assertion removal.
The fixture process clock is fixed to the source episode and restored afterward.

have **4/4** useful positives. The corrected, removed, and rebuilt states each exclude unsupported
current evidence: **6/6** withdrawals, with the old prose still readable as history. Source bytes
match the frozen input and each declared edit, and there are zero L3 fact rows. Actual answers
return **1/4** supported positives; one is `verification_rejected` and two are
`verification_unavailable`. All six stale
states have no reflected answer evidence or citations: five `empty_draft`, one
`verification_rejected`. These typed outcomes are not pooled into a claim of perfect answer quality.

Deterministic production-path checks include 27 focused reflection cases and the full **4744-test**
suite. Build, lint, dead-code checks, installed-package and lifecycle smoke tests, documentation
build, formatting, and repository-safety checks passed after the review/fix rounds.

## Limits

The final controls preserve the configured derive/answer models, reasoning settings, timeouts,
and explicit answer output cap of 1024. Embeddings are disabled only in isolated positive controls,
so their retrieval correctly reports `no_embedding_model`, `no_vector_index`, and `partial_index`.
Invalid structured answer-verifier responses are recorded as `verification_unavailable`, not
successful answers or safe-negative coverage. No private sources or production settings are changed.

This repair covers exact selected support changes/removal, malformed lineage, legacy qualification,
independently supported conclusions on one page, summaries, revision sealing, and rebuild. It does
not establish representative inference, universal causal conclusions, new L3 graph traversal, or
reliable natural admission; admission remains a separate scope in [#174](https://github.com/tenphi/akno/issues/174).
