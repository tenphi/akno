## Failure and resulting behavior

A dated member catalog already wakes synthesis when a schedule crosses its boundary. On unchanged
0.18.4, the held-out reproduction generated a rejected rewrite, then ordinary 20-hour rejection backoff
left the obsolete Upcoming heading in place through the remaining cycles and restart/rebuild. This was
a measured draft/admission failure, not a failure to select the overview.

A complete declared catalog showing missing membership or stale temporal presentation now permits one
immediate draft correction against the original body, exact same evidence and validation feedback.
The original stale classification is included even if the first candidate partly corrected it.
Supported unprotected temporal headings are renamed in place: heading count, depth, section order,
protected text, and separate list/table presentations remain constraints. An old overview label is
historical wording supported by that overview, not evidence that a member record lacks an outcome.

Every corrected draft passes the same discourse/rewrite guards, semantic verification, separate
curator decision, sealed-source checks, and ordinary write budget. No authority is expanded. A second
rejection retains normal backoff. Incomplete catalogs, malformed verdicts and unavailable verification
cannot become semantic correction feedback. Already-current cosmetic drafts get no extra attempt.
The bounded first rejection remains visible as `draftAttempts` and `draftRejections`.
