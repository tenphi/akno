# V65 code review — round 1

## Disposition

No actionable blocker found in the current V65 diff against `03ce30b`.

## Source attachment during retention

The new generation rule follows the bounded design: it permits a named entity to qualify the record the source identifies while preserving the later component/action at its original specificity. It explicitly separates record identity from component ownership and denies authority to competing records, unrelated neighboring names, subject/page metadata, or unresolved attachment. Explicit source ownership remains preservable.

This does not create an anaphora exemption or a deterministic acceptance path. Candidate prose still passes the existing source-readable identity checks and complete-source semantic verifier. The regression matrix exercises the important contrasts: named record, explicit ownership, invented ownership, competing record, unrelated neighbor, changed polarity, document-silence broadening, and changed object. Negative model verdicts remain verification holds without repair or coercion.

Finite limitation: the tests necessarily stub semantic judgment, so they prove prompt delivery and mandatory verifier enforcement rather than that the model will always resolve record attachment correctly. The plan states that limit. A generated `Zephyr QX-100's motor` remains rejectable when the source establishes only a Zephyr exclusion record and generic motor repair.

## Group-relative epistemic experiencer

Generation now states the exact semantic boundary exposed by V64: `unknown to us` may become an equivalent finite `we do not know`, but not bare/global unknownness, Ada's personal ignorance, nobody's knowledge, unknowability, or record-level non-establishment. It also prevents neighboring Ada predicates from lending their actor to the group-relative clause and prevents importing an independent private-frame limit.

The source-audit guidance matches the existing coordinate schema:

- absent group experiencer: actor `omitted` with null answer anchor;
- present but substituted experiencer: actor `changed` with its actual anchor;
- present bare/global epistemic predicate: qualification `generalized` or `changed` at its actual anchor;
- corresponding false proposition/action/qualification dimensions and distinct mismatches.

That mapping avoids the V62 malformed omitted-plus-non-null coordinate. A schema-valid negative alignment remains an ordinary `verification_rejected` outcome. Genuinely impersonal source unknownness and unselected private clauses remain explicitly outside the requirement.

The English/Russian operation table covers faithful dative and finite paraphrases, missing and substituted experiencers, misleading outer attribution, nobody/unknowable/record substitutions, and full mandatory semantic rejection. The page filter correction appropriately isolates the intended evidence; reconstructing `answer_segments` tests the actual verifier payload rather than a nonexistent convenience field.

One deliberate modeling choice remains: the contract treats an epistemic experiencer as an action-argument dimension as well as qualification scope. That is consistent with the existing shared contract for material epistemic predicates and the unchanged all-three gate; it is not a new schema or threshold.
