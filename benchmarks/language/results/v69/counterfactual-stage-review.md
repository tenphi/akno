## Smallest coherent correction

The row-71 loss supports a generation-presentation correction before any further nominal grammar enumeration. For Russian rendering of a selected counterfactual, the existing generation/translation contract should direct the model to use an explicit conditional clause when natural: `если бы` must govern the source antecedent, the consequence must remain subjunctive, and a separate clause must retain the actual-world nonoccurrence and not-current qualification. Rows 59 and 65 demonstrate that this form passes the existing floors while preserving the source. This is a presentation rule only; it must not supply an antecedent, consequence, actor, purchase, or current-coverage conclusion absent from the selected record.

The same procedural instruction should say to insert every required `named_source_reference.exact_spelling` verbatim after translating the surrounding prose. Row 54 already uses the desired conditional form and was withheld only because the model transliterated the name despite the existing general instruction. A localized final-rendering checklist is more directly tied to the failure than another broad “preserve names” reminder, while the current exact-name floor continues to fail closed.

I do not recommend adding `заключался в том`, then successive synonymous nominal introductions, to [`counterfactual-wording.ts`](../../../../packages/core/src/memory/counterfactual-wording.ts). Each admitted nominal shape needs complete left scope, antecedent/consequence binding, nonpurchase, not-current status and retraction boundaries. Enumerating introductions addresses this one surface form and grows a high-risk grammar. Explicit `если бы` is already a general, source-faithful Russian construction and is already recognized. The row-71 hold can remain the conservative fallback when generation does not follow the presentation guidance; neither local floor should be weakened.

Meaningful invented-data checks should cover:

- a Russian generated answer with an explicit `если бы` antecedent, conditional repair consequence, nonpurchase and not-current clause passing the local floor and reaching the existing verifier;
- otherwise identical drafts with a changed purchaser, covered component, year, purchase occurrence or current-coverage status reaching the verifier and being rejected by mandatory semantic controls;
- a required invented source name retained byte-for-byte in Russian output, with a transliterated form still held locally;
- the row-71 nominal shape documented as outside the deterministic grammar unless a separately reviewed structural grammar change is later justified.

This recommendation changes no schema, field order, cap, model, call count, retry behavior, source authority, or semantic acceptance rule.
